КАЛЬКУЛЯТОР ПОЗОРА — BEDWARS

Это исходный Android Studio проект. Готовый APK здесь не собран: в среде создания отсутствуют Android SDK/Gradle, а загрузить их отсюда невозможно.

КАК СОБРАТЬ APK НА ПК:
1. Установи и открой Android Studio.
2. Выбери Open и укажи распакованную папку BedWarsCalculator.
3. Дождись Gradle Sync. Если Android Studio попросит SDK Platform 35 — установи её через SDK Manager.
4. В меню Build выбери Build Bundle(s) / APK(s) → Build APK(s).
5. После сборки нажми Locate. APK обычно находится в app/build/outputs/apk/debug/app-debug.apk.
6. Передай APK на телефон, открой файл и разреши установку приложений из этого источника, если Android спросит.

Приложение шуточное: вводишь убийства, смерти, падения в пустоту, сломанные кровати и победы — получаешь мемный вердикт и индекс позора.
